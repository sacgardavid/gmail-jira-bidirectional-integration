## [1.0.0] - 2026-09-15

### Added

- Automatic Jira issue creation from incoming Gmail messages.
- Email replies converted into Jira comments.
- Jira comments sent back to the original email sender.
- Gmail thread preservation.
- Jira attachment support.
- Duplicate message prevention.
- Email/Jira loop prevention.
- Automated processing with time-based triggers.
- Secure Jira API token storage using Google Apps Script Script Properties.
- Gmail and Jira integration through their official APIs.
- Configurable project and email settings.
